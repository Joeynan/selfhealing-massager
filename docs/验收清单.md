# 验收清单

记录日期、操作人、电脑系统、源码提交、Python／依赖版本、两板版本与 Release SHA。设备 ID／IP 只记录在私有验收文档；密码不记录。将“通过／失败／未测”和失败证据分别填写，不用软件回执替代实物结论。

## 软件离线检查

- [ ] 私有仓库取得的源码能在中文／空格路径安装；缺少配置会从示例创建，不覆盖旧设置。
- [ ] 模型官方来源及 SHA256 校验通过；Python 3.12 和锁定依赖可导入，安装后依赖检查通过。
- [ ] `tools/package_team.py audit` 通过，提交内容没有真实 Wi-Fi、备份、历史图像或黑板二进制。
- [ ] 控制台离线模式可以打开网页，不连接设备、摄像头或枚举串口。
- [ ] 8890／8877 占用时给出明确提示；未知服务不被结束，旧目录服务不能被错误复用。
- [ ] 运行控制回归与固件主机测试；5 秒保持、新确认刷新、切换、无手 800ms、旧／重复／过期帧、断线、迟到指令和启用前缓存测试通过。
- [ ] 小智构建成功，目标 ESP32-S3、专用板型和 4MiB 应用分区正确，应用不超过分区；补丁重复应用可识别，未知组件版本失败。
- [ ] Release／回滚及 `--build-dir` 本机构建离线检查通过；错误报告、篡改镜像、错误设备、错误分区、错误串口在写入前拒绝。
- [ ] 源码配网首次或内容改变时应用，配置不变时保留串口修改；非法配置及满 10 项新增不写入或删除旧网络。保存／读回失败不记录成功，并尝试恢复旧配置；持续存储故障需实机排查。私有头文件与含密码构建镜像不提交。

## 先在舵机断电时验收设备

- [ ] 小智和黑板的设备身份、固件及校准一致；保留固件、配置与回滚路径。
- [ ] 小智 v9 应用只写 `0x200000`，读回校验通过；Wi-Fi／NVS、视觉采集固件未改。
- [ ] 黑板 Wi-Fi 私有配置本地构建；EEPROM 配对与校准保留，开机先脱离输出。
- [ ] 电池长按开机、运行长按关机、USB 长按待机／恢复、开机松手保护及短按无动作正确。
- [ ] 滚轮方向、数据页保持、全圆屏黑底、动画边缘和低电量提示正确；实体表情与网页同步。
- [ ] Wi-Fi 画面持续更新，绿灯只表示新鲜采集；移走手表情保留约 5 秒，新手势立即切换。
- [ ] 退出识别服务、USB 待机、摄像头故障、两板断线均停止旧动作；恢复只使用新会话与新输入。
- [ ] 小智拔电脑 USB 用电池时继续取图和显示，电脑识别服务仍正常运行；Wi-Fi／IP 改变可按指南恢复。

## 接通独立 5V 后观察实物

先确认独立供电与共地，先单路、再三路。每次测试有回执不等于实物转动。

| 通道 | 2000µs、最长 500ms 短测次数 | 是否启动 | 恢复 1500µs 后是否停转 | 其他通道是否停止 | 异常与测试 ID |
|---|---:|---|---|---|---|
| D1／捶打 | 5 | 待填 | 待填 | 待填 | 待填 |
| D2／揉搓 | 5 | 待填 | 待填 | 待填 | 待填 |
| D3／轻捏 | 5 | 待填 | 待填 | 待填 | 待填 |

- [ ] 三路各自完成 2 秒模拟并回中立；连续短测不需每次重新启用。
- [ ] 每次仅目标通道运动，新手势切换后旧通道停止；停止按钮、手动禁用和长按关机可停止。
- [ ] 真实捶打、揉搓、轻捏各 20 次，正确识别各不少于 18 次；覆盖静态／动态揉搓、左右手、距离、旋转、双手冲突和轻捏混淆。
- [ ] 动画与日志同时开启时识别至少 4 帧/秒；静态确认不超过 1 秒，动态揉搓新周期完成后 500ms 内确认。
- [ ] 完全无手后 800ms 内设置中立；5 秒保持只由新有效确认刷新，普通未识别与重复帧不续期。
- [ ] 断网、识别服务退出、黑板重启、摄像头错误及时设置中立；机械停转耗时另记，不据脉宽推断。

## 交付时如何描述结果

每项结论注明验证平台与证据：源码自动测试、Mac 构建／离线检查、Windows GitHub Actions、Windows 实物烧录、设备显示、机械运动分别记录。CI 在实际推送运行前标记“已准备、未运行”；新系统没有设备测试时标记“待实机验证”。不把旧设备或旧版本证据当作当前使用者电脑的结果。
