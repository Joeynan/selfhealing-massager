# Watcher 控制台 · 当前 v9 使用说明

Mac 使用工程根目录的 `启动控制台.command`，Windows 使用 `启动控制台.ps1`，打开 http://127.0.0.1:8890/。首次安装、两板烧录及 Wi-Fi 修改请按 [使用指南](../../docs/使用指南.md) 操作。当前固件为 `watcher-servo-controller-v9-wheel`，使用 **Watcher Wi-Fi 摄像头 → 电脑手节点识别 → Watcher 控制 → 黑色 ESP8266 板 → 舵机**。Watcher、电脑与黑色板需处于可互通的 Wi-Fi 网络，电脑识别服务需持续运行。Watcher 用电池时可以拔掉电脑 USB，识别仍在电脑上完成。

## 电源和滚轮

| 当前状态 | 操作 | 结果 |
|---|---|---|
| 电池供电、已关机 | 长按滚轮约 3 秒，再松手 | 开机到表情页，首次松手不重复执行操作 |
| 运行中 | 按满 3 秒，再松手 | 先请求中立并禁止新动作；松手后电池供电时关机，USB 供电时进入软件待机 |
| USB 软件待机 | 长按 3 秒，再松手 | 唤醒到表情页，建立新画面会话；等待中立回执和新鲜识别后再接受动作 |

短于 3 秒的按压不执行电源或控制操作。滚轮顺时针一个卡位进入数据页，逆时针返回表情页；到达端点后保持，不循环。表情页显示当前手势动画；数据页显示网络、摄像头、识别、输出和电量。切换页面时识别与联动继续运行，按住或待机期间不切页。

## 手势和输出

设备就绪后持续默认启用输出，正常手势和短测无需反复点击启用，也无需勾选供电确认。动作仍等待连接、中立回执、配置同步和新鲜输入。点击停止会回中立并保留默认启用，下一次新确认手势可继续；手动禁用会暂停自动输出，需手动启用恢复。

稳定手势保留原有 5 秒保持：同一手势的新确认刷新期限，新手势立即切换。移走手或输入过期 800ms 时停止运动；故障、失联和待机仍受停止守卫约束。表情保持不表示舵机持续运行。

捶打对应 D1，揉搓对应 D2，轻捏对应 D3。默认中立 1500µs、运行 2000µs、50Hz，每次只运行一组；保存的自定义校准继续使用。软件回执和脉宽回报需结合实际转动、停转观察。

## 启动、地址和保存

小智地址读取本目录 `settings.json`，地址变化时可以指定：

```zsh
./启动控制台.command --wifi-camera --watcher-url http://小智IP:8080
```

入口使用本机 Python 3.12，完整 Mac 工程可优先使用已保留的基础解释器；各电脑创建自己的环境，不复制别人的 venv。摄像头使用 `work/watcher-control-runtime/venv`，Windows 解释器在 `Scripts/python.exe`，Mac 在 `bin/python`；识别源码直接在本目录 `camera/` 运行。校准、配置、日志和缓存保存在工程 `work/watcher-control-runtime/`，已有 `camera-data/config.json` 不覆盖。`runtime.json` 以运行目录为基准保存相对路径。

保留启动窗口，按 Ctrl+C 结束本次启动的服务。只有本次同时新建摄像头和控制台的诊断会话，退出时才向设备发送停止。复用前先核对软件/识别版本、当前工程元数据、监听进程和源文件；验证失败不切换来源或停止设备。两个已有服务均通过验证时只打开页面，不接管或停止原会话。若只有摄像头或控制台一个服务在运行，请在其原启动窗口关闭后重新启动完整链路。显式 USB 诊断仍可使用 `--mac-camera`，需配合原 USB 版固件。

首次安装使用根目录 `安装摄像头依赖.command`／`.ps1`，重建使用 `重建运行环境.command`／`.ps1`。运行与烧录依赖分别锁定在本目录 `requirements-runtime.lock`、`requirements-flash.lock`；可用本平台本地 wheels，不足时按固定版本联网补齐。模型从固定官方地址下载并校验 SHA256，私有 `settings.json` 只在不存在时从示例生成。详见使用指南。

## 离线验证

在工程根目录运行：

```zsh
./启动控制台.command --offline --no-browser --dashboard-port 8895
```

打开 http://127.0.0.1:8895/。离线模式不启动识别、枚举串口或摄像头，也不连接设备或切换来源。页面仅轮询两个由启动器保持绑定、未监听的本机端口，使用独立 `settings-offline-8895.json` 和 `dashboard-offline-8895.log`。保留启动器运行，按 Ctrl+C 结束该次离线服务；旧控制台可继续运行。`--no-browser` 也可用于正常启动。
